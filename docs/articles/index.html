irishbuoys - Articles

Dashboards and reports for the irishbuoys R package. All vignettes load pre-computed data from the targets pipeline.

Dashboards

Irish Buoys Explorer

  • 6 interactive pages: Max Wave, Signif Wave, Wind Speed, Wind vs Wave, Data, Reference
  • Rogue wave detection: Hmax / Hs > 2.0 criterion applied to all stations
  • Full historical data: Hourly observations from 5 buoys (M2-M6), 2019-present

Irish Buoys Analysis

  • Extreme value analysis: GEV and GPD models with return levels (10, 25, 50, 100 years)
  • Rogue wave detection: Events, conditions, gust factor analysis
  • Seasonal decomposition: STL trend and seasonal components

Data Quality

Telemetry

  • Data coverage: Station availability and freshness
  • Pipeline metrics: Target execution status and timing
  • Test and LLM usage: Test suite statistics and Claude Code costs

analysis_data Validation

  • pointblank report: Column existence, value ranges, station IDs
  • Physical bounds: Wave height 0-30m, wind speed 0-100 m/s, pressure 900-1100 hPa

rogue_wave_events Validation

  • pointblank report: Rogue ratio > 2.0, required columns, hmax > wave_height
  • Event count: Validates detected rogue wave events
