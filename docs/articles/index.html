📊 Irish Weather Buoys - Vignettes

Interactive dashboards and analysis vignettes for the irishbuoys R package. All vignettes load pre-computed data from the targets pipeline for reproducibility.

🌊 Dashboards

Irish Weather Buoy Explorer

  • 6 interactive pages: Max Wave, Signif Wave, Wind Speed, Wind vs Wave, Data, Reference
  • Rogue wave detection: Automatic identification of waves where Max Wave / Signif Wave > 2.0
  • Full historical data: Hourly observations from all 5 buoys (M2-M6), 2019-present

~14 MB HTML (includes all interactive charts)

📈 Analysis

Comprehensive Wave Analysis

  • Extreme value analysis: GEV and GPD models with return levels (10, 25, 50, 100 years)
  • Joint distribution analysis: Cross-correlations, M6 predictions, copula tail dependence
  • Rogue wave science: Worked example of how Signif Wave is calculated from raw measurements

~21 MB HTML (includes all interactive charts)

🔧 Technical

Pipeline Telemetry (if available)

  • Data coverage metrics: Completeness by station and time period
  • Pipeline performance: Target execution times and dependencies
  • Git activity tracking: Commits, branches, and development metrics

Debug Dashboard

  • Validation status: Data quality checks via pointblank
  • Pipeline health: Target status and error tracking
  • Session diagnostics: R version, packages, environment

✅ Data Quality (pointblank)

Analysis Data Validation

  • Comprehensive checks: Column existence, value ranges, station IDs
  • Physical bounds: Wave height 0-30m, wind speed 0-100 m/s
  • Interactive report: pointblank interrogation with pass/fail details

Rogue Wave Validation

  • Event validation: Rogue wave ratio > 2.0, required columns
  • Quality assurance: Ensures detected rogue waves meet criteria
  • Interactive report: pointblank interrogation for rogue events

📱 Interactive (WebR)

Shinylive Dashboard (experimental)

  • Runs in browser: No server required - pure WebAssembly/WebR
  • Interactive filters: Select stations, variables, date ranges dynamically
  • Portable: Share as static HTML file, works offline

Note: Initial load takes 30-60 seconds while WebR initializes
